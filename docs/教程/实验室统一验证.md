## 6 实物跟踪范围、软边界和停止

此项由C在实物旁看护，先用已验收的低速参数，不做撞限位试验。终端2：

```bash
ros2 param set /team43_tracking/visual_servo_node max_omega 0.08
ros2 param set /team43_tracking/visual_servo_node motion_enabled true
```

按顺序做：

1. **方向**：把指定码放在中心右侧/下侧，小幅移动，确认两轴让像素误差减小；反向立即false停止，按[云台跟踪](云台跟踪.md)核对控制符号，不能加增益。
2. **长时与大角**：在已验证工作区间内平缓移动目标，使实际视线方向变化超过25°，持续跟踪至少30秒；再由现场人员缓慢改变底盘朝向。记录真实角度、关节反馈、图像误差及状态。不能再出现台架“本次转动达到角度范围”或15秒到点锁停；关节/IMU故障仍应停止。
3. **软边界**：只在留有充足机械余量的实测工作区间内，慢慢引导接近一侧软件边界，观察对应朝外速度归零；将目标移回区间内，应能向内跟踪。两轴正负方向分别留记录。若边界接近硬端，不做这一步，先选择更保守工作区间，不把软件保护当机械制动保证。
4. **失去目标**：遮住指定码约0.5秒，观察立即衰减/零速度与实物停止；移回后按状态观察恢复。记录停止时间、余转角及是否靠近机构极限。
5. **人工停机**：运动中执行下列false，确认停止；然后在安全小幅运动中验证主终端Ctrl+C能结束全链并停机。参数终端无法联系时使用现场停机手段。Ctrl+C测试会结束桥和LIO，之后必须新会话重新对齐/建图。

   ```bash
   ros2 param set /team43_tracking/visual_servo_node motion_enabled false
   ```

可在试验前另开采样30～60秒，采样记录新增的`joint_states`与控制status；不要为采样单独开桥：

```bash
python3 -B tools/collect_field_evidence.py --seconds 60 --output-dir "$LAB_RUN/tracking_range"
```

**通过条件**：方向正确、长时与所需范围不中断、边界向外阻挡且向内可恢复、遮挡/false/Ctrl+C停止。记录实际停止延迟和余转，不用“发了三帧零”推断电机已经停。MCU复位/IMU断流的真实故障演练只在现场确认安全时做；正常新会话epoch变化及运动未自动重开也应记录。

测试后恢复已验收参数副本；不要把临时调低/调高的值误当正式PID。完整轮次前再次按比赛页一键启动，保持新会话不中断。
